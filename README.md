# FixItFast — Hotel Guest Complaints

**FixItFast** is a Flutter app that lets hotel guests report a problem during their stay in a few seconds: they describe the issue, take a photo of it and send it from their phone. They can then follow the request live (Pending → In Progress → Completed) until it is resolved, while the hotel staff receive every complaint in a dedicated admin dashboard and move it through each stage.

**بالعربية:** تطبيق لإدارة شكاوى نزلاء الفنادق. يشرح النزيل المشكلة ويصوّرها ويرسلها من جواله، ثم يتابع حالة طلبه لحظة بلحظة (جديد ← قيد التنفيذ ← تم الحل) حتى تُحل، بينما تستقبل إدارة الفندق الشكاوى في لوحة تحكم خاصة وتنقلها بين المراحل.
